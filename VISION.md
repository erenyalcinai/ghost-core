# Vision — the north star this was built toward

Ghost is not a "bot" or an "assistant". It is the owner's **autonomous institution and
extended mind**: powerful, autonomous, loyal to one person, and under that person's control.
The line runs from Jarvis toward Vision — but the will always stays with the owner.

## Six dimensions

1. **From agent to institution.** Not one orchestrator with an anonymous worker pool, but
   persistent specialist departments (engineering, intelligence, finance, operations) with their
   own agents, tools and memory; delegating, accountable. An army, not a one-person army.
2. **From tool to tool-master.** Not bound to a single tool. An engine-agnostic orchestrator that
   picks the right instrument for the job (coding engines, automation engines, the MCP universe,
   raw shell/HTTP). *Status: engine plurality and failover are live; automatic tool synthesis was
   removed because it was an unconnected aspiration and may return with a real run+verify layer.*
3. **From program to self-designing.** Evolves its own architecture, department schema and
   processes. *Code changes pass tests and human approval.*
4. **From assistant to mind.** A live world model, not flat files: an entity graph of people,
   companies, projects and relations, plus foresight. Something that remembers the owner's world
   better than the owner and sees ahead.
5. **From tool to economy.** A self-financing agent: operating, marketing and growing the owner's
   products, optimising cost, giving birth to new products. An asset that earns, not a cost line.
6. **From application to platform.** Talks to other agents, exposes capabilities outward, can
   federate.

## Governance — the non-negotiable spine

A system this strong means control stays entirely with the owner.

- `/freeze` is always in human hands; it halts all autonomous action instantly.
- Autonomy starts with **reversible** actions; it expands only with evidence *and* approval.
- Money, legal, permanent deletion, outward communication **always** go to the owner.
- Every autonomous action is in the audit log; a weekly transparency report.
- Graded authority: read-free → reversible-write → permanent-write → spend.

An uncontrolled system is not powerful; it is only dangerous. These limits are the
precondition of power, not its obstacle.

## Core principle

However far the six dimensions reach, the first building block is always the same: the
**core** — event bus + tool registry/router + agent organisation + memory + governance.
Departments, economy, mind — all of it sits on that core. See [ARCHITECTURE.md](ARCHITECTURE.md)
for what exists and what does not.
